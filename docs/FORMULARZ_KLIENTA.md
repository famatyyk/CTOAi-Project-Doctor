# Formularz zlecenia — CTOAi Project Doctor

Skopiuj ten formularz do Ko-fi, Discorda lub e-maila.

```text
1. Nazwa projektu:
2. Link do repozytorium albo sposób przekazania kodu:
3. Główny język / framework:
4. Co projekt robi w jednym–dwóch zdaniach:
5. Największy obecny problem lub pytanie:
6. Czy raport ma być po polsku czy po angielsku?
7. Czy w repozytorium są dane, których nie wolno analizować?
8. Potwierdzam, że mam prawo udostępnić ten kod do statycznego przeglądu: tak/nie
```

## Zasady przekazania kodu

- Usuń `.env`, klucze prywatne, tokeny, dane klientów, bazy danych i pliki logów.
- Nie wysyłaj haseł ani kluczy w wiadomości.
- Jeśli repozytorium jest prywatne, użyj czasowego dostępu read-only lub
  przygotuj zredagowany ZIP.
- Project Doctor nie uruchamia kodu projektu; wykonuje jedynie statyczny odczyt.
